# Day 13 – Debugging

## Topics Covered

- Identifying syntax errors
- Identifying runtime errors
- Identifying logical errors
- Reading error messages and tracebacks
- Using `print()` to debug programs
- Using breakpoints
- Testing code step by step
- Finding and fixing bugs
- Understanding common Python errors
- Debugging existing programs

## Project

Day 13 did not contain a standalone project. Instead, the day focused on debugging exercises designed to identify, understand, and fix errors in Python programs.

## What I Learned

- How to read Python error messages and tracebacks.
- How to identify where an error occurs in a program.
- How to distinguish between syntax, runtime, and logical errors.
- How to use debugging techniques to find the cause of a problem.
- How to test different parts of a program to isolate bugs.
- How to use `print()` statements to understand what is happening inside a program.
- How to correct errors without changing the intended behavior of the program.
- How debugging is an important part of the programming process.

## Challenges

- Understanding what Python error messages are telling me.
- Finding the actual cause of an error when the reported line is not necessarily the root cause.
- Identifying logical errors that do not produce an error message.
- Tracking how variables change as the program runs.
- Understanding why a program can run successfully but still produce the wrong result.
- Debugging code written by someone else.

## Future Improvements

- Practice debugging larger programs.
- Learn more advanced debugging techniques in VS Code.
- Become more comfortable using breakpoints and the debugger.
- Practice identifying bugs without relying immediately on the solution.
- Learn how to write tests that help detect bugs automatically.
